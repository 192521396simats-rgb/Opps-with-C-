## 📌 Project Description
This project demonstrates a **Student Record Management System** using Object-Oriented Programming concepts in C++.  
It includes:
- **Encapsulation**: Private data members with controlled access through public functions.  
- **Polymorphism**: Function overloading for grade calculation and function overriding for details display.  
- **Inheritance**: Student class derived from Person class.  
- **Multiple Records**: Handles multiple students using vectors.

## ⚙️ How to Run
1. Open Dev-C++ or any C++ IDE.  
2. Compile `StudentRecordManagement.cpp`.  
3. Run the program to see student details and grades.
